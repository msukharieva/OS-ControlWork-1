# Контрольне завдання №1
**Варіант 22. «Юриспруденція (Суд)»**

## Етап 1. Визначення предметних аналогів базових об’єктів файлової системи

| UML-роль | Сутність ПрО | Обґрунтування |
|---|---|---|
| **Actor** (рольовий клас) | Юрист | Виконує дії над провадженням та документом. |
| **Aggregate** (клас-контейнер) | Провадження | Містить документи як свої елементи; є аналогом каталогу. |
| **Part** (клас-елемент) | Документ | Належить до провадження; є аналогом файлу. |

**Тип зв’язку між Провадженням та Документом — агрегація.**
*Обґрунтування:* Документ може існувати окремо від конкретного провадження (його можна продублювати та перемістити). Видалення провадження (`rm -r`) є граничним випадком, коли воно знищується разом із усіма документами.
*Кратність:* Провадження `1` містить `*` (багато) Документів.

## Етап 2. Визначення семантичних відповідників 

| Операція ПрО | Операція Bash-команди | Bash-команда | Обґрунтування вибору |
|---|---|---|---|
| увійти | перейти у каталог | `cd` | Семантичний синонім: пряме значення для контейнера. |
| сформувати | створити каталог | `mkdir` | Семантичний синонім: поява нового контейнера. |
| підготувати | створити файл | `touch` | Семантичний синонім: поява нового елемента (документа). |
| завірити | змінити файл | `nano` | Зміна вмісту наявного елемента (згідно з Правилом 2). |
| оглянути | переглянути каталог | `ls` | Огляд вмісту контейнера (провадження). |
| вивчити | переглянути файл | `cat` | Перегляд вмісту елемента. |
| — | перемістити каталог або файл | `mv` | У ПрО немає дії, що змінює розташування. |
| — | створити копію каталогу | `cp -r` | У ПрО немає дії, що створює копію контейнера. |
| продублювати| створити копію файлу | `cp` | Семантичний синонім: створення копії елемента. |
| — | видалити порожній каталог | `rmdir` | У ПрО немає дії, що видаляє порожній контейнер. |
| — | видалити каталог | `rm -r` | У ПрО немає дії, що видаляє контейнер. |
| — | видалити файл | `rm` | У ПрО немає дії, що видаляє елемент. |
| опечатати | — | — | Дія над контейнером без семантичного аналога серед 12 Bash-команд. |

*(Примітка: В описі Варіанта 22 для елемента "Документ" наведено рівно 4 дії, і всі вони мають прямі семантичні відповідники згідно з методичними вказівками. Тому друга дія без відповідника над елементом у тексті ПрО фізично відсутня).*
